# 单机知识库应用框架 · 开发指引

> 本文把《Linux 手册》这套 **PyQt5 + SQLite 单机知识库** 架构整理成可复用的开发指引。
> 目标：照着做，两小时内换出一个《MySQL 手册》《Python 速查》《网络排查手册》之类的
> 新程序，界面、主题、增删改、收藏、删除恢复、分类管理、抓取管道全部现成。
>
> 全套代码约 5700 行（含测试），核心 8 个模块约 2500 行，无 Web 引擎、无网络运行时依赖，纯离线。

---

## 一、这套框架适合做什么

**适合**：内容形态是「分类 → 分组 → 词条」的离线知识库、命令速查、手册、题库、
术语表。词条字段固定为：名称、摘要、正文、语法、示例、注意、标签、来源。

**不适合**：富媒体播放、多端同步、账号体系、实时协作 —— 这些需要引入网络与
服务端，已超出本框架。

**技术选型基线**（换语言/框架前先看这张表）：

| 项目 | 选择 | 原因 |
|---|---|---|
| GUI | PyQt5 5.15 | 系统自带、单文件可跑、QSS 换肤成本低 |
| 存储 | SQLite（WAL + 外键） | 单文件、零部署、FTS 可后加 |
| 富文本 | `QLabel` 富文本 + 自绘代码卡 | 免 Web 引擎，启动 <1s |
| 图标 | QPainter 自绘矢量 | 本机只有位图 emoji，Qt5 画不出彩色字形 |
| 单实例 | `QLocalServer` / `QLocalSocket` | 按数据库路径哈希做实例 id |
| 明确不用 | QtWebEngine / QtSql / PySide6 / tkinter / GTK / Electron | 体积、启动速度、依赖复杂度 |

| 位置 | 改什么 |

| [app.py](app.py) `APP_NAME` / 单实例 id 前缀 | 换成你的程序名 |

### 3. 准备种子 JSON

结构固定，字段全部可选（除 `name`）：

```json
{ "version": 1, "categories": [
  { "key": "mysql", "name": "MySQL 速查", "groups": [
      { "name": "账号与权限", "entries": [
          { "name": "GRANT", "summary": "授予权限",
            "content": "正文 Markdown", "params": "语法行",
            "example": "```bash\nGRANT ALL ON db.* TO u;\n```",
            "note": "⚠ 高风险操作", "tags": "权限", "source": "来源标识" } ] } ] } ] }
```

字段约定（重要）：

- **速查型词条**：只填 `summary`，`content` 留空 → 详情页只显示一句摘要 + 示例卡
- **教程型词条**：`summary` 是一句话，`content` 是长正文 → 详情页自动去重，
  正文里重复摘要的首句会被识别并跳过（`dup_body` 判定）
- `example` 用 ```` ```bash ```` 围栏包裹 → 渲染成带「复制」按钮的代码卡
- `content` 超过 300 字时不再额外渲染 `example` 卡（避免同一段代码出现两遍）

## 四、数据层（src/db.py）

### 表结构

| 表 | 字段 |
|---|---|
| `categories` | `id, key UNIQUE, name, sort` |
| `groups` | `id, category_id → categories CASCADE, name, sort` |
| `entries` | `id, category_id CASCADE, group_id SET NULL, name, summary, content, params, example, note, tags, source, fav, views, created, updated` |
| `settings` | `key PK, value` —— 主题、字号、窗口几何、上次分类 |
| `history` | `id, entry_id, viewed_at`（上限 500） |
| `trash` | `id, entry_json, deleted_at` —— 词条完整 JSON 快照，上限 200 |

### Store API 分组

| 组 | 方法 |
|---|---|
| 查询 | `categories(with_settings)` `groups(cat_key, only_with_entries)` `entries(cat_key, query, fav_only, group_id, limit)` `entry(id)` `category_entry_count(key)` `stats()` |
| 浏览 | `view(id)`（计数 + 写历史） `history(limit)` `clear_history()` |
| 写入 | `save_entry(dict)`（无 id 即新增） `toggle_fav(id)` |
| 删除保护 | `delete_entry(id)` `to_trash(id)` `trash_list(limit)` `trash_count()` `restore_from_trash(id)` `clear_trash()` |
| 分组 | `ensure_group(cat_key, name)` `delete_group(id)` `rename_group(id, name)` `move_group(gid, cid)` |
| 分类 | `add_category(key, name)` `add_category_named(name) → (cid, err)` `rename_category(id, name)` `delete_category(id, keep_in_trash)` `reorder_categories(ordered_keys)` |
| 设置 | `setting(key, default)` `set_setting(key, value)` |
| 种子 | `seed_from_json(path, replace)` `export_json(path)` `import_json(path, replace)` |

### 三个设计要点

1. **删除走快照**：`to_trash` 把整条词条序列化成 JSON 存 `trash`；
   `restore_from_trash` 恢复时若原分类/分组已不存在，会按快照里的
   `category_key/category_name` 重建 —— 删分类不会丢数据。
2. **`sort` 决定顺序**：`categories()` 是 `ORDER BY sort, id`。拖拽排序就是重写
   `sort`；`settings` 固定排最后（`reorder_categories` 里显式置 `len(ordered_keys)`），
   否则会和知识库分类撞同一个 sort 值导致错位。
3. **中文搜索用 LIKE 不用 FTS5**：FTS5 默认分词器不切中文。实现是 `LIKE` 命中后
   用 `CASE` 给「名称前缀匹配 > 名称包含 > 摘要包含 > 正文包含」排优先级。

### 加字段

```python
self.db.execute("ALTER TABLE entries ADD COLUMN risk INTEGER DEFAULT 0")
```

`sqlite3` 的 `ALTER TABLE ADD COLUMN` 足够用；老库升级在 `__init__` 里
`PRAGMA table_info` 检查后补列即可。

## 五、主题层（src/theme.py）

### 语义色板

`PALETTES["light"|"dark"]` 共 23 个语义键，**代码里永远不出现十六进制色值**：

```
win card card2 tab hover border border2 text text2 text3
accent accent2 accentBg accentBg2 link sel warn warnBorder warnText
code codeBorder shadow
```

### 样式入口

```python
QApplication.instance().setStyleSheet(theme.qss(mode, base_pt, code_pt))
```

主题切换 = 重新 `setStyleSheet` + 重绘自绘控件（`set_theme` / `set_mode`）。

### cls 类名约定（QSS 选择器）

控件用 `setProperty("cls", "...")` 挂类，QSS 用 `QXxx[cls="..."]` 命中：

| 类名 | 用途 |
|---|---|
| `tab` `icon` `mini` `arrow` | 分类按钮 / 图标按钮 / 紧凑图标按钮 / 左右箭头 |
| `primary` `ghost` `danger` | 主按钮 / 次要按钮 / 危险按钮 |
| `card` `cardTitle` `cardDesc` `pageTitle` `rowName` `rowMeta` `hint` | 卡片与其内部文字 |
| `item` `itemName` `itemSum` `itemFav` | 列表词条行 |
| `group` `groupCount` | 分组标题 |
| `form` `formLabel` `search` `status` `copy` `codeCard` `body` `note` `chip` | 表单与详情 |

`objectName` 用于结构性容器：`topbar listPanel listArea detailArea detailInner
detailCard metaBar appTitle search`。

### 三条铁律（违反必出事故）

1. **不在代码里写死颜色。** 卡片/文字一律靠 `cls` 走全局 QSS。
   写死过一次，切深色时设置页就变成白底黑字（本项目真实事故）。
2. **字体用 `setFont`，不要在 QSS 里写 `font-weight`。**
   QSS 设粗体时 `QLabel.sizeHint()` 仍按非粗体计算，粗体实际更宽 → 末尾字符被切半截。
3. **自绘控件要在主题切换时重绘。** `GroupHeader` 持有 `pal`，切主题后必须
   `rebuild_list()` 重建；图标按钮要重新 `setIcon(icons.xxx(pal["text2"]))`。

## 六、组件层

### GroupHeader（自绘分组标题）

- **为什么自绘**：`QPushButton` 内放子控件（图标+文字+计数）会吃掉点击，
  `clicked` 永不触发 —— 本项目真实踩过。
- 实现：`paintEvent` 画圆角底/箭头/计数，`mousePressEvent` 发 `clicked` 信号，
  `enterEvent/leaveEvent` 做 hover 与跑马灯。
- 箭头字符 `▸/▾` 是自绘文本，不依赖字体图标。
- 名称过长时 `enterEvent` 启动 `QTimer` 偏移绘制起点，`leaveEvent` 复位。

### EntryItem（词条行）

- 名称用 `MarqueeLabel` + **显式 `setFont` 粗体**（见主题铁律 2）
- `setTextFormat(Qt.PlainText)`：命令名含 `| > 2> && || !!`，富文本会被当 HTML 解析
- 摘要去 Markdown 标记后截断 110 字

### TabBar（横向分类栏）

- `QScrollArea` + 水平滚动条常隐，两侧 `◀ ▶` 按钮
- 同步箭头状态的信号要**三个都连**：`valueChanged`、`rangeChanged`、`resizeEvent`。
  只连 `valueChanged` 时，分类增删改变了滚动范围却不会触发同步（真实事故）
- 滚轮：`viewport`/`inner`/每个按钮都装 `eventFilter`，`angleDelta` 换算成
  `max(60, 视口宽*0.25)` 的位移
- **高亮互斥用代码手动做**：`set_active(key)` 遍历 `setChecked(k == key)`。
  不要用 `setAutoExclusive(True)` —— Qt 的互斥按钮组**不允许全部取消选中**，
  进设置页时旧分类按钮灭不掉（真实事故）
- 重建列表时 `setParent(None)` 再 `deleteLater()`，否则残留控件

### TopBar

- logo（自绘）+ TabBar（stretch 1）+ 搜索框（固定宽）+ 新增按钮 + 设置图标 + 主题图标
- 设置**不占分类位**：`set_tab("settings")` 时所有分类按钮取消选中、齿轮按钮高亮
- `show_category()` 必须调用 `set_tab()`，否则快捷键/拖拽排序后高亮不跟随

### MarqueeLabel

- 静止时 `QFontMetrics.elidedText(..., Qt.ElideRight, width())` → 省略号收尾，
  绝不硬裁半字
- 悬停且溢出才启动定时器滚动，移开复位
- `resizeEvent` 里重算（面板宽度变化后不残留旧裁切）

### CodeCard（代码卡）

- 只读 `QPlainTextEdit` + 固定高度（`行数*行高+14`，上限 14 行）+「复制」按钮
- 复制后按钮文字变「已复制 ✓」，`QTimer.singleShot(1600, 复位)`
- 放进 `QScrollArea` 时必须调 `_relayout()`（`layout().activate()` +
  `updateGeometry()` + `processEvents()`），否则高度算成 0（真实事故）

### icons.py

`chevron / chevrons / gear / moon / sun / plus / search / logo / grip / star`，
全部 `QPainter` 画在透明 `QPixmap` 上返回 `QIcon`。

> 用 emoji 字符做图标在本机必然失败：只有位图版 `NotoColorEmoji.ttf`，
> Qt5 渲染成残缺方框。验证方法：统计 pixmap 非透明像素数，emoji 只有 ~28 个，
> 正常字形 80+。

### markdown_view.py

- `inline_html(text, pal)`：先转义再处理 `` `x` `` 与 `**x**`
- Qt 富文本**不支持** `background` 简写与 `border-radius`，只能用
  `background-color` + `color` + `font-family`
- `render(md, lay, pal, base_pt, caption)`：切块 → 标题/列表/表格/代码卡
- 构造 `QLabel(html)` 会在 `setTextFormat` 前解析 HTML → 必须先建空 label、
  设格式、再 `setText`

### SettingsPage

- 卡片工厂 `card(title, hint)` 只挂 `cls`，不写颜色
- 分类管理 = `QListWidget` + `InternalMove` 拖拽 + 三路提交（见第九节陷阱）
- 删除分类/词条都是**两步确认** → 进 `trash` → 可在设置页逐条恢复

## 七、单实例机制（app.py）

```python
def instance_id(db_path):
    return "linuxHandbook-" + hashlib.sha1(os.path.abspath(db_path).encode()).hexdigest()[:12]

# 启动先连已有实例
if try_connect_existing(iid):      # QLocalSocket 连上就发 b"raise"
    sys.exit(0)                    # 已聚焦旧窗口，本进程退出
server = QLocalServer()
server.newConnection.connect(win.wake_up)   # 收到 b"raise" → showNormal+raise_+activateWindow
```

要点：

- `QLocalServer` / `QLocalSocket` 在 **`PyQt5.QtNetwork`**，不在 `QtCore`
- 实例 id 绑定数据库路径 → 换 `--db` 就是另一个实例，可同时开多个库
- 崩溃残留的 socket 文件要 `QLocalServer.removeName(iid)` 后再 listen

## 八、内容抓取管道

### 探测数据源（先做这步，能省掉大量解析工作）

有些「大全」页是 JS 动态加载的，正文里没有数据。做法：

1. 抓索引页，搜 `commandData` / `jsonDataURL` / `$.getJSON(`
2. 找到形如 `wp-content/themes/.../xxx-data.json` 的接口，直接拿结构化数据

本项目《Linux 命令大全》就是这么找到 441 条命令的（`linux-command-data.json`）；
《Docker 命令大全》是静态 HTML，只能解析 `<h3>` + `<a>`。

### html2md.py 用法

```python
from html2md import convert
md = convert(html)          # 提取正文容器 → Markdown
```

- `extract_article()` 只取正文容器，甩掉导航/广告/评论
- 代码块用 `CODE_MARK = "\x00"` 占位，最后统一还原 —— 否则全局
  `re.sub(r'`{3,}', '`')` 会把代码围栏压平（真实事故）
- `NOISE_LINES` 去掉「运行实例 »」这类按钮文字

### 抓取脚本模板（tools/build_*.py）

固定五件事：

1. **并发**：`ThreadPoolExecutor(max_workers=6)`，441 页 49 秒
2. **缓存**：`.cache/<板块>/<文件名>.html`，存在且 >2000 字节直接读盘 → 重跑不联网
3. **重试**：3 次退避；**写缓存前先 `os.makedirs(CACHE, exist_ok=True)`**
   —— 目录不存在会让写盘抛异常，被重试逻辑吞掉后表现为「抓到 200 页却全解析成空」
4. **URL 归一**：数据源里链接形态不统一（`/linux/x.html`、`x.html`、完整 URL）
   → 三分支拼接
5. **正文清洗**：去掉页面标题行与导航噪音；与摘要重复的首句跳过

章节切分（分类页里一个页含多个子命令时）：

```python
parts = re.split(r"^###\s+(.+)$", md, flags=re.M)   # [前导, 标题1, 内容1, ...]
```

### 合并与导入

```bash
python3 tools/build_docker_manual.py                       # → data/docker_seed.json
python3 tools/merge_seed.py data/docker_seed.json          # 并入 data/seed.json
python3 -c "import sys;sys.path.insert(0,'src');from db import Store; \
           Store('data/linux.db').seed_from_json('data/docker_seed.json')"
```

`seed_from_json(replace=False)` 是**追加合并**（新分类自动创建）；
`--rebuild` 是整体重建。

### 两条测试纪律

1. **期望值不许写死。** 词条数、分类数一律从 `data/seed.json` 现场统计：

   ```python
   _seed = json.load(open("data/seed.json", encoding="utf-8"))
   SEED_ENTRIES = sum(len(g["entries"]) for c in _seed["categories"] for g in c["groups"])
   ```

   数据一扩充，硬编码的 `== 195` 立刻假失败。
2. **视觉结论要落到像素。** 「深色模式没白底」不能靠读代码断言，要
   `widget.grab()` 后按亮度采样统计近白像素占比；「只有一个高亮」要扫描
   accent 色连续块数量（注意排除 logo 也是 accent 色）。

## 十、Qt 陷阱清单（本项目全部踩过）

| 现象 | 根因 | 修法 |
|---|---|---|
| 命令名末尾被切半字 | QSS 设 `font-weight` 时 `sizeHint` 按非粗体算 | 字体用 `setFont` 显式设置，QSS 只留颜色 |
| 进设置页旧分类按钮灭不掉 | `autoExclusive` 按钮组不允许全部取消选中 | 手动 `setChecked` 做互斥 |
| 拖完顺序没写库 | 内部拖放走「删除+插入」，不发 `rowsMoved` | `rowsMoved`+`rowsRemoved`+`rowsInserted`+`Drop` 事件四路提交，`QTimer(0)` 延迟 |
| 箭头按钮状态不更新 | 只连 `valueChanged`，滚动范围变化不触发 | 补 `rangeChanged` + `resizeEvent` |
| emoji 图标显示成方框 | 本机只有位图 NotoColorEmoji | 全部 QPainter 自绘 |
| 深色模式设置页白底 | 构建时把浅色值写进 `setStyleSheet` | 颜色全交全局 QSS 的 `cls` 选择器 |
| 分组标题点不动 | `QPushButton` 内放子控件吃掉点击 | 自绘 + `mousePressEvent` 发信号 |
| 命令名显示乱码 | `\| > &&` 被当 HTML 解析 | `Qt.PlainText` + 显式 `setText` |
| 摘要/表格/段落显示成 HTML 源码 | `QLabel(html)` 构造时按 AutoText 设了文本，之后 `setTextFormat(RichText)` 不重新解析 | 建空 label → 设格式 → `setText`（本项目表格与段落整批中招） |
| 代码卡高度 0 | `QScrollArea` 内布局未激活 | `_relayout()`：activate + updateGeometry + processEvents |
| 刷新后控件翻倍 | `QListWidget.clear()` 不回收 itemWidget | 清空前逐个 `setParent(None)+deleteLater()` |
| 列表残留旧控件 | `deleteLater()` 前未摘父 | 先 `setParent(None)` |
| 富文本背景无效 | Qt 富文本不支持 `background`/`border-radius` | 只用 `background-color`+`color`+`font-family` |
| 抓到页面却全空 | 写缓存目录不存在，异常被重试吞掉 | 写盘前 `os.makedirs(..., exist_ok=True)` |
| **详情页内容不全**（正文只剩一句摘要） | 去重判定"正文以摘要开头就整块不渲染"，而教程页摘要就是正文首段 | 只剥掉重复的**首段**（`strip_dup_lead`），其余正文照常渲染 |
| **界面卡死**（点开某词条不返回） | 段落分支的 `while` 与进入条件互补，遇到「以 `|` 开头不以 `|` 结尾」的行时 `i` 不推进 → 死循环 | 每个分支都要保证 `i` 前进，末尾加兜底分支 |
| 检查"标签被切字"大量误报 | 富文本标签的 `text()` 返回 **HTML 源码**，直接量它的宽度必然超长 | 先 `QTextDocument().setHtml(t).toPlainText()` 再量；固定像素阈值也会误报短标题 |
| 正则匹配不到条目 | 目标被 `<code>` 包着，`[^<]*?` 跨不过 | 正则加可选标签 `(?:<code>)?` |
| `ImportError: QLocalServer` | 它在 `QtNetwork` 不在 `QtCore` | 改 import |
| 后台启动的程序被杀 | 沙箱回收后台进程（exit 137） | 交付时让用户在终端自己启动 |

## 十二、可直接复用的最小骨架片段

新程序入口（照抄改名即可）：

```python
#!/usr/bin/env python3
import os, sys
sys.path.insert(0, os.path.join(os.path.dirname(os.path.abspath(__file__)), "src"))
from PyQt5.QtWidgets import QApplication
from db import Store
from main_window import MainWindow

APP_DIR = os.path.dirname(os.path.abspath(__file__))
app = QApplication(sys.argv)
app.setApplicationName("MyHandbook")
db_path = os.path.join(APP_DIR, "data", "my.db")
store = Store(db_path)
store.ensure_categories()
if store.is_empty():
    store.seed_from_json(os.path.join(APP_DIR, "data", "seed.json"))
win = MainWindow(store, APP_DIR)
win.resize(1280, 820)
win.show()
sys.exit(app.exec_())
```

单实例、抓取管道、测试套件按需从 `app.py` / `tools/` 里搬。
